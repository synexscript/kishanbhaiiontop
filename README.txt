BIRTHDAY SURPRISE WEBSITE
=========================

HOW TO OPEN
-----------
1. Keep all folders and files in the same structure.
2. Open the Birthday-Surprise folder.
3. Double-click index.html.
4. The website will open in your browser.

HOW TO ADD YOUR PHOTOS
----------------------
1. Open assets/images.
2. Add your photos.
3. Rename them:
   photo1.jpg
   photo2.jpg
   photo3.jpg
   photo4.jpg

4. Keep the filenames exactly the same, or update the
   image paths in js/diary.js.

HOW TO CHANGE DIARY TEXT
------------------------
Open js/diary.js.

Find the diaryPages array.
Edit the title and text for each page.

HOW TO CHANGE THE FINAL MESSAGE
-------------------------------
Open js/main.js.

Edit:
finalLoveNote
finalSignature

IMPORTANT
---------
- Do not move CSS or JS files outside their folders.
- Keep the folder names unchanged.
- Internet is needed to load the Google Fonts.
- The website itself works locally without a server.
